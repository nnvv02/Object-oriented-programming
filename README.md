# Каталог книг з графічним інтерфейсом Swing

Застосунок реалізує простий каталог книг мовою Java з графічним інтерфейсом на основі Swing. Програма дозволяє зберігати інформацію про книги, переглядати список публікацій, шукати книги за назвою, а також зберігати та завантажувати каталог з файлу.

## Можливості застосунку

- додавання книги до каталогу;
- видалення книги за назвою;
- оновлення інформації про книгу;
- пошук книги за повним або частковим збігом назви;
- перегляд усіх доданих книг у списку;
- збереження каталогу у файл;
- завантаження каталогу з файлу;
- обробка ситуації, коли книгу з указаною назвою не знайдено.

## Вимоги для запуску застосунку

- встановлений JDK;
- Java 8 або новіша версія;
- операційна система Windows, Linux або macOS;
- термінал або IDE для компіляції та запуску Java-файлів.

## Структура проєкту

```text
src/
├── Publication.java
├── Book.java
├── Catalogue.java
├── BookNotFoundException.java
└── BookGUI.java
.gitignore
README.md
```

`Publication.java` - базовий клас публікації з назвою та роком видання.

`Book.java` - клас книги, який наслідує `Publication` і містить автора, видавництво та жанр.

`Catalogue.java` - клас для роботи з колекцією публікацій, пошуку, додавання, видалення, оновлення та серіалізації.

`BookNotFoundException.java` - власний клас винятку для ситуації, коли книгу не знайдено.

`BookGUI.java` - графічний інтерфейс застосунку на Swing.

## Збірка проєкту

Відкрийте термінал у кореневій папці проєкту та виконайте команду:

```bash
javac src/*.java
```

Після компіляції у папці `src` будуть створені `.class` файли.

Для запуску застосунку виконайте:

```bash
java -cp src BookGUI
```

## Користування застосунком

Після запуску відкриється вікно каталогу книг. Заповніть поля назви, автора, видавництва, жанру та року видання, після чого натисніть кнопку `Додати книгу`.

Для видалення книги введіть її назву в поле `Назва` та натисніть `Видалити книгу`.

Для оновлення книги введіть її назву та нові дані в усі поля, після чого натисніть `Оновити книгу`.

Для пошуку введіть частину або повну назву книги в поле пошуку та натисніть `Пошук`. Щоб повернути повний список, натисніть `Скинути параметри пошуку`.

Для збереження каталогу натисніть `Зберегти у файл` і виберіть місце збереження. Для відновлення каталогу натисніть `Завантажити з файлу` та виберіть раніше збережений файл.
